# Публичные документы РИЯДА

Статические копии двух публичных страниц для подключения приложения RIYADA к Meta.
Версия политики: 2026-10-26.1. Источники: https://riyada.art/privacy-policy и https://riyada.art/data-deletion.

При изменении оригинальных документов необходимо обновить эти копии. Контакт: riyada.art@ya.ru.
