Удаление данных обращения

Инструкция для обращений с сайта, из Instagram и ВКонтакте.

Как отправить запрос

  1. Напишите на riyada.art@ya.ru с темой «Удаление данных».
  2. Укажите источник обращения: сайт, Instagram или ВКонтакте. Для социальной сети укажите имя аккаунта; для заявки с сайта — контакт, который использовали при отправке.
  3. Оператор проверит сведения, необходимые для идентификации обращения, и при необходимости свяжется с вами для уточнения запроса.

Какие данные удаляются

Относящиеся к обращению сообщения, контактные данные, карточка заявки и история обработки удаляются из систем, управляемых Оператором, если для дальнейшего хранения отдельных сведений нет законных оснований.

Удаление данных обращения не удаляет ваш аккаунт Instagram или ВКонтакте. Сообщения и сведения в самой социальной сети удаляются отдельно средствами этой платформы.
